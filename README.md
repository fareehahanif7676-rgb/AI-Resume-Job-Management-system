# AI Resume & Job Management System

## About Project
This is a Python-based AI Resume & Job Management System.
It helps users analyze their resumes and manage job information.

## Features
- Resume PDF upload
- AI Resume Analysis
- Resume improvement suggestions
- Job management
- Voice feature
- User-friendly interface

## Technologies Used
- Python
- AI / Gemini API
- PDF Processing
- Streamlit
- Text-to-Speech

## Purpose
The purpose of this project is to help users improve their resumes and manage job-related information using python and AI
